# API CLI V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `api` CLI described in `docs/design/api-cli-v1.md`, with automated fake-service tests and a handoff point for real-service credential setup.

**Architecture:** Keep CLI parsing in `cmd/api` as a thin adapter over `internal/runner`. The runner owns profile catalog loading, credential-store abstraction, auth application, redaction, request execution, response envelopes, and command output policy.

**Tech Stack:** Go standard library, `golang.org/x/term` for masked input, `github.com/zalando/go-keyring` for OS keyring, `httptest` for fake services.
